# section-notes（阅读10｜文献总结与结构化笔记）

笔记只做**抽取**，不做改写：每一条都来自原文原句或可数项的统计，因此可以逐条翻回对应页码核对。

## 它解决的问题

读完一篇论文写笔记，常见的三种退化：

1. **脑补**：把"作者暗示的方向"写成作者没有断言过的结论。
2. **无锚点**：记了一堆要点，回查时不知道出自哪一页。
3. **丢结构**：只记了摘要级信息，方法/实验里的关键数值全丢。

本 Skill 先还原章节树，再按"断言句 + 数值 + 图表题注"三类证据填充，每条带 `page` 与 `bbox`。

## 用法

```bash
python3 src/run_case.py --case input/case.json --out work
```

`case.json` 里 `inputs` 指向 PDF；给多个 PDF 会自动生成 `comparison` 对比表。

## 输出字段

| 字段 | 含义 |
|---|---|
| `notes[]` | 每篇文献一份笔记 |
| `notes[].sections[]` | 章节 → `key_sentences`（带页码的原句） |
| `notes[].key_numbers[]` | 关键数值及其上下文，带 `page`/`bbox` |
| `notes[].figures` / `tables` | 图表题注清单 |
| `notes[].open_questions` | 固定的复核问题（不代替你的判断） |
| `outline` | 由各节首句汇总出的汇报提纲 |
| `comparison[]` | 多篇输入的横向对比表 |

## 判据

要点句子按三类线索打分后取前若干条：

- 断言线索（`we show / propose / 我们提出 / 实验表明`）
- 指标线索（百分比、pp、perplexity、准确率等）
- 引文线索（`[12]` 这类标记）

只保留得分 > 0 的句子，因此安静的方法描述段可能不进笔记，此时会在 `uncertainty` 里说明。

## 限制

- 纯抽取式，不做归纳与批判性总结；这是刻意的，代价是笔记不如人写紧凑。
- 章节切分依赖版面（字号与编号），极端排版下可能把标题并入正文。
- 扫描件无文字层则无法生成笔记。
- `open_questions` 是固定的通用自查项，不是针对本文的发现。

## 最小示例

```bash
python3 src/run_case.py --case demo/case.json --out work
```

输出会给出章节数、关键数值条数、图表题注数量，并附页码锚点。
